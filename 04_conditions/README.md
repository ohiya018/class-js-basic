## 01 if文の基本

-if文の基本形 if(もし~なら)
条件式が成り立った（`true` の）ときだけ、中括弧 `{ }` の中の処理が実行されます。

if (条件式) {
  // 条件式が true（正しい）のときに実行される処理
}


-二択の時のif文 if...else(もし~ならA,そうでなければB)

if (条件式) {
  // 条件式が true のときの処理
} else {
  // 条件式が false のときの処理
}


-三つ以上の選択肢時のif文(if ... else if ... else)
条件を順番に判定していきたい場合は、else if を挟みます。上から順に判定され、最初に当てはまったブロックだけが実行されます

const score = 75;

if (score >= 90) {
  console.log('評価：S（大変優秀です）');
} else if (score >= 70) {
  console.log('評価：A（良好です）');
} else if (score >= 50) {
  console.log('評価：B（もう少しです）');
} else {
  console.log('評価：C（再試験です）');
}


**判定は「上から順」に行われる**

`else if` は上から評価され、**一度条件に合致すると、それ以降の `else if` や `else` は無視されます**。
そのため、数値の範囲を判定するときは、厳しい条件（大きい数字など）から順に書くのが原則です。
