# 04_条件分岐と属性操作
このフォルダには「04_条件分岐と属性操作」の授業用練習コードおよび課題データを保存します。

ゴール
- **if文（条件分岐）** の基本構文（`if` / `else if` / `else`）を理解し、状況に応じて実行する処理を分岐できる。
- 比較演算子（`===`, `!==`, `>`, `<`, `>=`, `<=`）と論理演算子（`&&`, `||`, `!`）を正しく使いこなせる。
- HTML要素の属性（`src`, `href`, `type`, `disabled` など）をJavaScriptから取得・設定・削除できる（`getAttribute`, `setAttribute`, `removeAttribute`）。
- クラス操作（`classList`）と属性操作の**役割の違い**を理解し、適切に使い分けられる。
